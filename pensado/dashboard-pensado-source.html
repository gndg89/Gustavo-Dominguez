Sobre este login

Este dashboard usa un inicio de sesión de demostración (usuario/contraseña fijos, revisados en el navegador) para que puedan empezar a usarlo y probarlo ya mismo. No es seguridad real: cualquier persona que vea el código fuente de la página puede ver o saltar la verificación, y no hay cuentas separadas por persona ni datos privados protegidos.

Para una versión con login de verdad (contraseñas con hash, sesiones seguras, permisos por persona) hace falta un servidor propio con base de datos de usuarios — eso requiere hosting y, si quieren, dominio propio. Lo podemos construir en el repositorio de GitHub cuando estén listos para ese paso.
