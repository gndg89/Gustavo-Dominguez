Sobre este login

Este dashboard usa un login real de servidor: usuario y contraseña vienen de variables de entorno, la contraseña se compara con bcrypt y la sesión se guarda en una cookie firmada por el servidor, no en el navegador.

Todas las secciones se guardan en una base de datos en el servidor (SQLite en un volumen persistente de Railway), así que lo que agreguen, editen o eliminen queda ahí la próxima vez que lo abran, desde cualquier dispositivo.
